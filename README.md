# 자산일기 깔끔이버전

담백한 금융 대시보드 스타일의 개인 자산 일기 PWA입니다. 자산·가계부·거래·리밸런싱을
기록하고, 모든 데이터는 **내 기기(브라우저) 안에만** 저장됩니다.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다(예: `asset-diary-clean`). Public으로 두어야 무료 Pages를 쓸 수 있습니다.
2. 이 폴더의 파일을 **폴더 없이 전부 저장소 맨 위(루트)에** 올립니다.
3. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 선택하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 열립니다.
5. 아이폰 Safari로 그 주소를 열고 **공유 → 홈 화면에 추가**를 누릅니다.

## 파일 구성

```
index.html              앱 화면
styles.css              디자인
app.js                  기능
sw.js                   오프라인 캐시(서비스워커)
manifest.webmanifest    홈 화면 앱 정보
.nojekyll               GitHub Pages가 파일을 그대로 제공하도록 하는 빈 파일
LICENSE.md, NOTICE.md   저작권·이용 고지
```

## 시세

- 국내주식(코스피·코스닥 전종목)과 해외주식(S&P500·나스닥100)은 GitHub에 매일 갱신되는
  공개 `prices.json`에서 받아옵니다. API 키가 필요 없습니다.
- 코인은 CoinGecko, 환율은 Frankfurter를 씁니다(키 불필요).
- 금과 그 밖의 해외 거래소 종목만 Twelve Data 키가 필요합니다(설정에서 입력).

## 업데이트할 때

파일을 새로 올린 뒤 홈 화면 앱을 완전히 종료했다가 다시 열면 새 버전이 반영됩니다
(`sw.js`의 `CACHE` 이름이 바뀌어야 캐시가 교체됩니다). 설정 화면 맨 아래의 버전 표기로
실제 반영 여부를 확인할 수 있습니다.
